# Интерактивные визуализации WarpTorch

Эта страница демонстрирует возможности интерактивной визуализации численных методов в WarpTorch.

## Сходимость схем конечных разностей

### Анализ сходимости

WarpTorch использует схемы конечных разностей разных порядков точности:

**Важные наблюдения:**
- **2-й порядок:** Ошибка ~ O(h²) — базовая точность
- **4-й порядок:** Ошибка ~ O(h⁴) — используется в WarpTorch по умолчанию
- **8-й порядок:** Ошибка ~ O(h⁸) — максимальная точность, но больше вычислительных затрат

### Почему 4-й порядок?

WarpTorch использует 4-х порядковые схемы как оптимальный баланс:
- **Точность:** ~ 10⁻⁴ для сеток 64³
- **Производительность:** Отличная векторизация на GPU
- **Память:** Разумные требования для 4D пространств-времени

## Распределение энергии в варп-метриках

### Энергетический анализ

Сравнение энергетических требований разных варп-метрик:

#### Метрика Алькубьерре
- **Требует экзотической материи:** ~ 10⁶⁴ кг (теоретически)
- **Нарушает все энергетические условия**
- **Практическая реализуемость:** Неизвестна

#### Метрика Ленца (2021)
- **Требует экзотической материи:** ~ 10²⁰ кг (значительно меньше)
- **Может удовлетворять энергетическим условиям**
- **Практическая реализуемость:** Более реалистична

#### Метрика Ван den Брока
- **Требует экзотической материи:** ~ 10³⁰ кг
- **Использует микро-пузырь для сокращения требований**
- **Практическая реализуемость:** Промежуточный вариант

#### Метрика Шварцшильда
- **Требует экзотической материи:** 0 (вакуумное решение)
- **Не нарушает энергетические условия**
- **Практическая реализуемость:** Естественные черные дыры существуют

## Интерактивные примеры в коде

### Анализ сходимости в Python

```python
import torch
from core.metrics.alcubierre import get_alcubierre_metric
from core.solver.christoffel import get_christoffel_symbols
from core.solver.ricci import get_ricci_scalar

def test_convergence(grid_sizes=[16, 32, 64, 128]):
    """Анализ сходимости схемы конечных разностей"""
    errors = []

    for size in grid_sizes:
        metric = get_alcubierre_metric(
            grid_size=(1, size, size, size),
            v=1.5,
            R=6.0,
            sigma=4.0,
            device=device
        )

        # Вычисление скалярной кривизны
        ricci_scalar = get_ricci_scalar(metric)

        # Ошибка: отклонение от ожидаемого значения
        expected = compute_expected_ricci(metric)
        error = torch.abs(ricci_scalar - expected).mean().item()
        errors.append(error)

    return grid_sizes, errors

# Построение графика сходимости
grid_sizes, errors = test_convergence()
plot_convergence(grid_sizes, errors)
```
