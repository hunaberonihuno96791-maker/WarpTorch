# Author System Examples

This page demonstrates the author system with various examples.

## Example 1: Core Team Member

```md
---
slug: feature-announcement
title: New CUDA Kernels
authors:
  - omar
tags: [feature, cuda, performance]
---

Excited to announce our new CUDA kernels!
```

## Example 2: Multiple Authors

```md
---
slug: research-paper
title: Warp Drive Stability Analysis
authors:
  - omar
  - janedeveloper
tags: [research, paper, collaboration]
---

Our latest research on warp drive stability...
```

## Example 3: Guest Author

```md
---
slug: guest-tutorial
title: Advanced Tensor Calculus
authors:
  - name: Dr. Physics
    title: Visiting Professor
    url: https://university.edu/physics
    email: physics@university.edu
tags: [guest-post, tutorial, advanced]
---

Today we'll explore advanced tensor calculus...
```

## Example 4: Community Contributor

```md
---
slug: community-spotlight
title: Community Project Spotlight
authors:
  - name: Community Member
    title: Open Source Contributor
    url: https://github.com/communitymember
    github: communitymember
tags: [community, spotlight]
---

Featuring amazing work from our community...
```

## Author Card Appearance

Each blog post automatically displays an author card with:

- **Profile picture** (or automatically generated avatar)
- **Author name** (linked to their profile if available)
- **Job title or role**
- **Social media links** (GitHub, Twitter, LinkedIn, Email)

## Team Integration

All configured authors automatically appear on the [/team](/team) page, creating a comprehensive team directory.

## Best Practices

1. **Use author keys** for team members (easier maintenance)
2. **Provide full details** for guest authors (better attribution)
3. **Keep social links current** (encourages engagement)
4. **Use professional photos** (builds credibility)
5. **Update titles regularly** (reflects current roles)
