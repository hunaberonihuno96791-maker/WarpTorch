# Welcome to WarpTorch Documentation

WarpTorch is a high-performance, GPU-accelerated General Relativity (GR) toolkit designed for simulating, analyzing, and visualizing warp drive spacetimes.

## Features

- **Massive Acceleration:** GPU-accelerated tensor computations
- **Comprehensive Metric Library:** Classical and novel warp metrics
- **Advanced Field Solvers:** 4th-order finite difference stencils
- **Spacetime Flow Diagnostics:** Energy condition validation
- **Web-Ready Export:** JSON exporters for WebGL frontends

WarpTorch is a modern Python/PyTorch port of the pioneering MATLAB project WarpFactory, providing unprecedented performance for numerical relativity simulations.
